xTra Player 3.0 (Android, Kotlin + Jetpack Compose + Media3/ExoPlayer 1.11.1)
Desenvolvido por xTra Soluções

Recursos: provedor Xtream Codes (servidor/usuário/senha) ou lista M3U, canais agrupados por
emissora (Band (3) > Band, Band Sports...), filmes e séries com preview na tela inicial,
perfis, perfil infantil e controle parental (PIN) para conteúdo +18, favoritos, e formas de
ver a tela no player (Ajustar, Esticar PC 800x600, Preencher, Preencher 4K).

Como gerar o APK:
1) Suba esta pasta para um repositório no GitHub.
2) Aba Actions > "Build APK" > Run workflow (ou só dê push).
3) Baixe o artefato "xtra-player-apk" (app-debug.apk) e instale no celular.
Ou abra a pasta no Android Studio e rode.
